# Smart Hostel Leave Application System

## About the Project

The **Smart Hostel Leave Application System** is a web-based application made using **Python Flask** and **MySQL**.

It helps students apply for hostel leave online. The warden can view the leave requests and approve or reject them.

This system reduces manual paperwork and makes the leave process easier.

## Features

### Student

* Login to the system
* Apply for leave
* Enter leave dates and reason
* View previous leave applications
* Check leave status

### Warden

* Login to the system
* View pending leave requests
* Approve leave requests
* Reject leave requests

### Notification

* Students can receive notifications about their leave status.
